# Terraform Examples

These files are **sanitized portfolio examples**, not the exact original team infrastructure code.

They demonstrate the type of AWS resources and Terraform structure used during the project without exposing team-owned code or identifiers.

## Before Running

The files intentionally use placeholders and are not intended to be applied to a real AWS account without review.

Do not add:
- real account IDs
- credentials
- private domains
- private bucket names
- private ARNs
